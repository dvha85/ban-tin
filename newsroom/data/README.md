# X emoji data

`emoji-test-15.1.txt` is the unmodified Unicode Emoji 15.1 data file from
<https://unicode.org/Public/emoji/15.1/emoji-test.txt>, downloaded 2026-11-03.
Its SHA-256 is `d876ee249aa28eaa76cfa6dfaa702847a8d13b062aa488d465d0395ee8137ed9`.
The Unicode license is in `UNICODE-LICENSE.txt`. The application recognizes
fully-qualified, minimally-qualified and unqualified entries, excluding
standalone components; it does not assert that this set matches the current
X application. The original Unicode 12.0 file used by the vendored parser is
retained for the independent Threads estimate and library comparison.
